Overview of Roles

Sterling Credentials assigns one or more of the following roles to each user account. A single person can hold multiple roles and switch between them from the sidebar without logging out.

RoleAlso known asPrimary function
Program DirectorProgram CoordinatorOverall program setup: cohorts, courses, users, PreClinical module
Clinical DirectorClinical CoordinatorReviews PCRs, manages clinical affiliates and shifts
Lead InstructorSkill Lab InstructorRuns lab sessions, records/evaluates skill performance
Adjunct—Assists with labs/simulations for an assigned cohort
Student—Enrolls, documents shifts/PCRs, uploads PreClinical requirements
Preceptor / Sim Coach—Verifies/signs off on student field or simulated shifts

Program Director Program Coordinator

1. Initial program setup roadmap

  1. Watch the SMC Brief Overview orientation video.
  2. Add team members (faculty/adjuncts).
  3. Enter your clinical affiliates.
  4. Explore a Sample Cohort to see how enrollment, labs, and shifts work.
  5. Create your first real cohort.
  6. Decide whether to use the PreAdmit/PreClinical Requirements module.
  7. Onboard students.

2. Add a faculty or staff user

  1. Go to Tools > Users.
  2. Click Create New User.
  3. Enter first name, last name, email address, and phone number.
  4. Check the box for each role the person needs (Student, Adjunct, Lead Instructor, Preceptor/Sim Coach, Clinical Faculty, Program Director, Clinical Director).
  5. Choose a Default Role — this is what they see first at login.
  6. Click Save Changes. Sterling emails the new user their login instructions automatically.

3. Create or clone a cohort

  1. Open the Cohort Editor.
  2. Find a cohort to clone (a sample cohort works for first-timers) and click Clone.
  3. Give the new cohort a title, choose which courses to reproduce, and click Clone again.
  4. Click Edit on the new cohort to adjust Basic Settings: start/end dates, payment method, and switch Make Live to Yes so students can enroll. Click Save.
  5. Re-open Edit and click Courses to manage Course Settings: add/rename/reorder Classroom (skills) or Clinical (report-writing) courses, assign skills, set date ranges, and control which report types are permitted per course.
  6. Use Edit SMC if you need to adjust the default CoAEMSP minimum tables.

4. Set up the PreClinical/PreAdmit Requirements module

  1. Setup: build your requirement list, tagging each item as PreAdmit or PreClinical.
  2. Review: approve or deny items as students upload them (you're emailed by default when new items arrive — adjustable in My Account).
  3. PreClin Reports: generate a PDF packet of student-submitted evidence for your clinical affiliates.

5. Onboard students

  1. Share your program's permanent enrollment URL so students can create their own account.
  2. Give each student the unique enrollment code for their cohort (found via the share icon on the cohort bar).
  3. Never manually add student accounts through the Users tool — this bypasses proper cohort enrollment and they won't display correctly under their cohort.

Clinical Director Clinical Coordinator

1. Add clinical affiliates

  1. Go to Tools > Affiliates and click Create new affiliate.
  2. Name the affiliate and set which report types are allowed there (Isolated Live, Practice, Simulation, Clinical, Field, Capstone/Internship).
  3. Add each Affiliate Location (e.g., station or department) with any notes students need — parking, entry procedure, food availability, etc. These notes are visible to students.
  4. Remember: simulation shifts need an affiliate too — create one representing your program/lab.

2. Reopen a closed shift

Shifts auto-close 72 hours after their documented end time.

  1. Navigate to the course, student, and shift in question.
  2. Click the gear icon and choose to reopen it.
  3. Note: reopening is logged and visible to anyone viewing the shift; faculty cannot see currently-open shifts in the list view, so don't be alarmed when it "disappears" after reopening.

3. Fix a shift's location or switch which shift you're viewing

  1. Open Shift Manager.
  2. Choose the Open Shifts or Closed Shifts tab.
  3. Click the map-pin icon on a shift to correct its location.
  4. Use Switch current shift if Sterling is still pointing to an old shift you need to edit.

4. Other regular tasks

  • Review and manage student PCRs.
  • Manage Evaluations (Tools menu).
  • View Respiratory Illness Screenings (Tools menu).
  • Pull a user's activity history: Tools > Users, click the user, open the User Activity tab.

Lead Instructor Skill Lab Instructor

1. Create a lab session

  1. Inside the relevant course, open Lab Manager and click Create New Session.
  2. Give it a title students will see (e.g., "While You Wait" for self-directed time).
  3. Select the skills to include and describe what should be accomplished in the session.
  4. Use the Staff Assignment tab to assign adjunct faculty — this auto-loads the correct cohort onto their dashboard when the session opens. If a substitution happens, adjuncts can just use "Switch Cohorts" instead.
  5. Set the date under Lab Session Date (sessions cannot be scheduled in the past).
  6. Save as Draft to hold it, or Save and Publish to move it to Scheduled (still requires manual opening later).

2. Open and run a lab session

  1. Find the session under Scheduled and click Open to make it live for students and faculty.
  2. Sessions in Drafts or Scheduled can be duplicated or edited (staff, skills, etc.) before opening.

3. Evaluate a student's skill performance

  1. Open the student's skill sheet and click the pen icon to record the performance in real time.
  2. Students can never evaluate themselves — this is enforced platform-wide to prevent fraudulent records. Only classmates or faculty can record a skill performance.

Adjunct Faculty

1. Make sure you're pointed at the right cohort

  1. Check the yellow cohort label under your name on the dashboard.
  2. If it's wrong (common if you weren't pre-assigned to a session, or you're substituting), click Switch Cohorts and choose the correct one.

2. Evaluate students

  1. Within an open lab session for your cohort, click the pen icon on a student's skill sheet to record their performance.

Student

1. Create your account and enroll

  1. Go to your program's unique enrollment URL (given to you by faculty) and create your account.
  2. Enter your cohort's unique enrollment code to complete enrollment.

2. Upload PreAdmission/PreClinical requirements

  1. Click Manage Documents in the left toolbar.
  2. Pay the fee or enter a coupon code if prompted.
  3. Work through "Items Awaiting Your Action" in both the PreAdmission and Clinical tabs, downloading and re-uploading forms as instructed.
  4. If one document covers multiple requirements (e.g., a combined shot record), screenshot and mark the relevant part for each requirement before uploading.
  5. Once everything is submitted, the interface shows "Nothing awaiting your action" and a count of items Pending Approval; you'll be emailed if anything needs revision.

3. Write patient care reports (PCRs)

  1. Choose the correct report type for the activity: Isolated Live (quick skills on live patients), Practice (no impact on SMC/skill counts), Simulation, Clinical (brick-and-mortar sites), Field (ambulance shifts), or Capstone/Internship (final paramedic ambulance shifts).
  2. Create the shift, document it, and dispatch it to your preceptor for sign-off.

4. Other tasks

  • Delete a duplicate or erroneous shift yourself via Shift Manager's gear icon (only students can do this).
  • View your own activity via the History Log button in the left toolbar.
  • Wait about 60 seconds after closing a shift before checking your SMC, since it fully rebuilds in the background.

Preceptor / Sim Coach

  • If you're an external clinical partner (not an in-house adjunct), you self-register through the preceptor verification flow on your own device when a student dispatches a shift to you.
  • If you're also an in-house adjunct acting as a simulation coach, your Program Director or Lead Instructor adds the Preceptor/Sim Coach role directly to your account via Tools > Users.
  • Use the short preceptor orientation video and printable quick-reference card provided by your program to learn the sign-off interface.

Understanding SMC (Student Minimum Competency)

What it is

SMC is the CoAEMSP Student Minimum Competency matrix — a mandated tracking/reporting format all CoAEMSP-accredited paramedic programs must submit, in effect since January 1, 2023 (next revision expected around January 2027). It documents that each student has accumulated minimum qualifying patient contacts and hands-on skills across set categories before graduation. Sterling calculates this matrix automatically as students document activity.

Where credits ("attainments") come from

Every SMC credit originates from one of three activity types: skills lab performance (recorded live during a Lead Instructor's Lab Session via the skill-sheet pen icon), simulation shifts (students document these themselves as Simulation-type PCRs, exactly like a real shift), and live shifts (Clinical, Field, or Capstone/Internship reports from real patient encounters). Choosing the correct report type and affiliate at the point of documentation is what routes the credit into the right SMC cell.

The report views

ViewTracks
Competencies MetTop-line met/not-met status per student across all tables
Table 1Patient age categories: Pediatric, Adult, Geriatric
Table 2Pathology/complaint categories: Trauma, Psychiatric/Behavioral, Obstetric delivery, Distressed neonate, Cardiac pathology/complaint, Cardiac arrest
Table 3Psychomotor skills on real patients (intubation, IV medication, IM injection, IO access, BVM ventilation, suctioning, FBAO removal)
Table 3 (Success Rates)Cumulative successful attempts / total attempts / success rate % for key skills (e.g., IV access, IV bolus meds, intubation)
Table 4Capstone Field Internship: team-leader-with-minimal-assistance count plus specific high-acuity skill minimums

Sterling's SMC view only reflects "Column 2" of each table, the CoAEMSP-mandated submission format. Column 1 activity is not included and must be tracked independently if needed.

Minimum thresholds

Each table shows a CoAEMSP "minimum number recommended" row and a "program minimum" row that your Program Director can raise above the CoAEMSP baseline via the Edit SMC tab in Cohort settings — useful for keeping related tables internally consistent (e.g., aligning a Table 1 neonate minimum with the Table 2 distressed-neonate total).

Best way to get everything accomplished

  • Have all paramedic students and lead/lab faculty watch the SMC Brief Overview video early, then Parts 1 and 2 (lab and simulation credits) within the first week of those activities. Save Part 3 (live shift credits) until a student is roughly 30% through live patient experience to avoid overwhelming them too early.
  • Print and distribute the quick-reference cards so students and faculty always know which credit lands in which table.
  • Get report types and affiliate settings correct up front — they directly determine how credits populate the SMC.
  • Faculty should periodically open the cohort's Full Summary SMC view rather than waiting until near graduation — the red/green color coding instantly shows which students are behind in which category, ages, pathology, or skill, while there's still time to schedule targeted make-up shifts, sims, or lab sessions.
  • Use simulation shifts deliberately to fill categories that are hard to guarantee live (pediatric, obstetric, psychiatric).
  • Remember SMC rebuilds after closing a shift — wait about 60 seconds before checking, and if it looks stale, have faculty reopen then re-close an old shift to force a rebuild.
  • Make sure preceptors are properly oriented, since their accurate documentation of skill attempts, successes, and team-leader assessments is what populates Tables 3 and 4 correctly.
  • Use the Print button on the Full Summary view to generate documentation for medical director review or accreditation records.

Scheduler (Shift Scheduling Tool)

The Scheduler provides a calendar-based view for building and assigning student shift blocks at clinical/field affiliate sites, letting Clinical Directors and Program Directors plan capacity ahead of time rather than reacting shift by shift.

Versions

  • Scheduler v2 (Beta) offers an updated calendar interface with a more visual, drag-friendly layout.
  • Scheduler v1 remains available under Tools if you prefer the legacy view.

Typical steps

  1. Open Tools > Scheduler.
  2. Select an affiliate and date range.
  3. Add shift blocks and assign eligible students or cohorts.
  4. Students can then see and claim their assigned or open shift slots when documenting.

Best practice: build out several weeks of scheduler blocks in advance for high-demand affiliates so students aren't scrambling for open slots.

Evaluations Tool

The Evaluations tool centralizes formal evaluation forms separate from routine shift documentation, viewable in two directions from Tools > Evaluations.

Evals by Student

Shows evaluations a student has completed of others: Lab/Simulation Coach evaluations, and Clinical/Field/Capstone shift evaluations.

Evals of Student

Shows evaluations completed about the student, including Affective (professionalism/behavior) evaluations and Preceptor evaluations, each built from a bank of sample rating questions.

Best practice: review the Evals of Student tab periodically alongside SMC to catch professionalism or affective concerns early, not just skill/patient-contact gaps.

Capstone Discussion Process

A structured reflective conversation between student and preceptor at the end of a Capstone/Internship shift, distinct from the standard sign-off.

The 4-step workflow

  1. Student documents the Capstone/Internship shift as usual and dispatches it to the preceptor.
  2. Preceptor reviews the documented shift and initiates the Capstone Discussion.
  3. Student and preceptor talk through the shift's key decisions, team-leading performance, and any high-acuity skills, with the preceptor recording qualitative notes.
  4. Preceptor finalizes the discussion and signs off, which factors into Table 4 (Capstone Field Internship) reporting alongside the standard skill/team-leader counts.

Best practice: encourage preceptors to complete the discussion the same day as the shift while details are fresh, and to be specific in notes since these support accreditation review.

Troubleshooting Common Issues

"Something isn't working"

First try a hard reload of the page; most display/sync glitches resolve this way before escalating to a support ticket.

Red alert / can't lock patient or close a shift

This usually means a preceptor hasn't confirmed sign-off yet, or a required field is incomplete. Check the preceptor confirmation status first, then verify every required field on the report.

"I cannot close my shift"

Confirm the preceptor has completed their portion, check for any skill or field left blank, and if the issue persists, open a Support Ticket with the shift ID rather than trying to recreate the shift.

Account & Mobile Access

Password changes

From My Account, use Change my Password; a reset link can also be requested from the login screen if locked out.

Mobile access

Sterling doesn't require a dedicated native app installation for basic use — the site is accessible via mobile browser. Check current Knowledge Base articles for any dedicated app availability, as this can change.

Best practice: bookmark the login page on your phone's home screen for quick field access during live/clinical shifts.

Cross-Role Best Practices

  • If something looks broken, reload the page first — most sync glitches resolve this way.
  • Always check the yellow cohort label before entering or reviewing data, to confirm you're pointed at the correct cohort.
  • Wait a full 60 seconds after closing a shift before checking SMC, since it needs to fully rebuild.
  • Use "Switch current shift" in Shift Manager if Sterling is still pointing at an old shift you need to edit.
  • For emergency force-closes or report-type/course corrections, open a Support Ticket with the shift ID rather than trying to work around it.
  • Keep at least one Clinical course open per cohort at all times so students always have access to reporting tools for edits.
  • Get report types and affiliate settings correct up front — they directly drive how the SMC matrix is populated.
